# 프로젝트 개요

## 1. 프로젝트 소개

Orbit은 게시글과 댓글을 통해 사용자 간 소통을 지원하는
커뮤니티형 스레드 게시판 웹 애플리케이션입니다.

## 2. 프로젝트 목표

- 게시글 및 댓글 기반 커뮤니티 기능 제공
- 프론트엔드와 백엔드의 역할 분리
- REST API를 통한 데이터 처리
- 데이터베이스를 활용한 게시글 및 회원 관리

## 3. 주요 기능

### 게시글

- 목록 조회
- 상세 조회
- 작성 및 수정
- 삭제

### 댓글

- 목록 조회
- 상세 조회
- 작성 및 수정
- 삭제

### 회원

- 회원 가입
- 회원 조회
- 정보 수정
- 회원 탈퇴

## 4. 구현 범위

- 완료된 기능과 미구현 기능을 구분하여 기록합니다.
- 인증 및 인가 기능은 실제 구현 상태에 따라 작성합니다.
